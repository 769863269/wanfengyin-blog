折腾两个周末，博客总算开张了。

## 为什么自己写

托管平台很方便，但样式不由自己说了算，总感觉是给别人打工。自己写的博客，每一像素都能讲出理由。另外这也是最好的练手项目：小而完整，从构建到部署全链路都能自己扛。

## 技术选型

最终定了 Vue 3 + Vite + TypeScript，纯静态输出。数据就是一组 Markdown 文件，构建时编译成类型安全的数据模块。不上 UI 组件库，阅读型站点的样式必须自己说了算。

目录结构一开始就定得很简单：

```text
├── articles/        # 文章源文件（Markdown）
├── public/          # 静态资源
├── scripts/         # 构建脚本（编译文章、预渲染）
└── src/             # 应用代码
    ├── components/
    ├── views/
    └── data/
```

## 踩的第一个坑

第一版把文章数据硬编码在 TS 文件里，加一篇新文章要改数组、小心插入位置、担心逗号。写到第三篇就受不了了，这直接催生了后来的 Markdown 发文流水线——那是另一个故事，后面单独写一篇。

> 独立博客的价值不在阅读量，在于有一块完全属于自己的地。

## 后续计划

接入评论、加归档页、写一套自动部署。这个坑会慢慢填，文章会慢慢写。这是第一篇文章，就当是奠基石。
