组合式 API 最大的变化不是写法，是「逻辑的组织方式」。
## 状态放哪
全局状态（主题、抽屉、搜索）在根组件挂载一次，子组件 useXxx 取同一实例；页面局部状态留在页面组件里。判断标准：谁的生命周期该管它。
> composable 抽取的时机是第二次重复，不是第一次出现。
## 类型体验
defineProps 泛型、computed 自动推导、ref 解包，TS 全程无断言。类型即文档，重构时尤其明显。
